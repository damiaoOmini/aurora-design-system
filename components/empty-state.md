# Empty State

Aurora Empty States contains a public `Empty state` component and a separate `Illustration` family.

## Empty state

- 27 variants.
- Icon: Motoristas, Veículos, Grupos, Relatórios, Cercas, Alertas, Dispositivos, Integrações, Mapa indisponível.
- Size: sm, md, lg.
- Optional Featured icon property.
- All Icon × Size combinations are represented.

The named icon variants are source-approved domain options. They are not permission to invent new domain variants.

## Illustration

- 12 variants.
- Style: Cloud, Credit card, Documents, Box.
- Size: sm, md, lg.
- All combinations are represented.

Illustration remains a distinct public family and should not be treated as synonymous with Empty state.

## Composition

Observed dependencies include Button, Featured icon, Badge, decorative background assets and icons.

## AI usage rules

- Preserve the approved icon and illustration families.
- Use Aurora semantic tokens and existing nested component contracts.
- Observed dimensions are examples, not global sizing tokens.
- Do not invent additional domain icons, empty-state causes, recovery logic, CTA behavior or content rules until those decisions are documented at Pattern level.
